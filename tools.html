Free Tools

These 3 free tools help stop phishing, malware, and ransomware. Each one has easy steps to set it up.

Tip: Always type the web address yourself. Never download a "security tool" from a pop up or an email link.
# Tool What it stops Cost
1 Malwarebytes Browser Guard Phishing and scam websites Free
2 Malwarebytes Free Malware already on your computer Free
3 Windows Security Ransomware Protection Ransomware locking your computer Free (already installed)

1. Malwarebytes Browser Guard

Stops: Phishing scams. This is a free add on for your web browser that blocks fake and scam websites before they open. It works on Chrome, Edge, Firefox, and Safari.

How to install it
  1. Open the web browser you use to go on the internet (Chrome, Edge, Firefox, or Safari).
  2. Type malwarebytes.com/browserguard in the address bar at the top and press Enter.
  3. Click the button to install it. It will take you to your browser's add on store.
  4. Click Add to Chrome (or Het in Edge, or Add to Firefox).
  5. A box will pop up. Click Add Extension.
  6. Done! It now works by itself. IF you try to open a scam website, it will show a warning page instead.

2. Malwarebytes Free

Stops: Malware. This free program checks your computer for harmful programs and removes them. It works on Windows and Mac computers. (Widows defender can aslo find threats for you and it is already installed).

How to install it
  1. Type malwarebytes.comin your web browser and press Enter.
  2. Click Free Download.
  3. Open the file you just downloaded. You can find it your Downloads folder.
  4. If Windows asks "Do you want to allow this app to make changes to your device?" click Yes.
  5. Follow the steps on the screen and click Install.
  6. When it opens, click Scan.
  7. If it finds anything, click Quarantine to remove it.
The free version only checks your computer when you click Scan, so run a scan once a week. You do not have to pay. if it asks you to buy or start a trial, you can skip it.

3. Windows Security Ransomware Protection

Stops: Ransomware. Windows 10 and 11 already come with free protection that stops strange programs from changing your Documents, Pictures, and Desktop folders. It is turned off at first, so you just need to turn it on. Nothing to download!

How to turn it on
  1. Click the Start button (the Windows logo at the bottom of your screen).
  2. Type Windows Security And click it to open it.
  3. Click Virus & threat protection.
  4. Scroll down and click Mangae ransomware protection.
  5. Turn the Controlled folder access switch to On.
  6. If Windows asks "Do you want to allow this app to make changes to your device?" click Yes.
If a program you trust gets blocked, you can allow it on the same page. Also keep a backup copy of your photos on a USB drive or in the cloud (like OneDrive) just in case.
