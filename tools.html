Free Tools

These 3 free tools help stop phishing, malware, and ransomware. Each one has easy steps to set it up.

Tip: Always type the web address yourself. Never download a "security tool" from a pop up or an email link.

1. Malwarebytes Browser Guard

Stops: Phishing scams. This is a free add on for your web browser that blocks fake and scam websites before they open. It works on Chrome, Edge, Firefox, and Safari.

How to install it
  1. Open the web browser you use to go on the internet (Chrome, Edge, Firefox, or Safari).
  2. Type malwarebytes.com/browserguard in the address bar at the top and press Enter.
  3. Click the button to install it. It will take you to your browser's add on store.
  4. Click Add to Chrome (or Het in Edge, or Add to Firefox).
  5. A box will pop up. Click Add Extension.
  6. Done! It now works by itself. IF you try to open a scam website, it will show a warning page instead.

2. Malwarebytes Free

Stops: Malware. This free program checks your computer for harmful programs and removes them. It works on Windows and Mac computers. (Widows defender can aslo find threats for you and it is already installed).
